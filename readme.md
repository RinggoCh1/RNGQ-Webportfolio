# EPC521 — Web Portfolio

A personal multimedia web portfolio developed for **EPC521: Web-Enabled Multimedia E-Language Production** at Universiti Teknologi MARA (UiTM).

This project showcases my academic work, creative abilities, multimedia production skills, and personal development through an interactive web-based portfolio.

## Overview

The portfolio brings together several aspects of my work and creative practice:

- **Home** — Introduction, skills, experience timeline and contact form.
- **E-Resume** — Academic background, skills, experience, and professional profile.
- **Videos** — Self-promotional and business promotional videos.
- **Artworks** — Digital artwork and promotional designs.
- **Tutorial** — A step-by-step, screenshot-based guide documenting the creation of a magazine cover.
- **About** — Background on the portfolio, credits and acknowledgements.

## Features

- Responsive layout with a mobile navigation menu.
- Animated background glow, cursor-following aura and typing role animation on the home page.
- Interactive e-resume: collapsible academic qualifications, expandable experience entries, skill-based highlighting and click-to-copy contact details.
- Optional background music with a live equaliser that carries across pages and pauses automatically while a video plays.
- Respects `prefers-reduced-motion` and includes keyboard focus styles.

## Technologies Used

- HTML5 — Website structure and content.
- CSS3 — Styling, layouts, animations, and responsive design.
- JavaScript — Interactive elements and website functionality.
- GIMP (with Photoshop-style tools) — Digital artwork and magazine cover design.
- DaVinci Resolve — Video editing.
- Cakewalk / Reaper — Audio production.
- Multimedia assets — Photography, video, and audio.
